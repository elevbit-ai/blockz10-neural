# De regras fixas a pesos que aprendem

# From fixed rules to weights that learn

Uma rede neural alterna duas operações: transformação linear e não-linearidade. A pirâmide Block 15/5 sempre teve as duas — só faltava deixá-las aprender. A rede não usa blocos: a rede é a pirâmide.

A neural network alternates two operations: linear transformation and nonlinearity. The Block 15/5 pyramid always had both — they just had to be allowed to learn. The network does not use blocks: the network is the pyramid.

01 · ESTADO / STATE

16 blocos

16 blocks

Origem + 15 blocos em 5 níveis. A entrada é um depósito: as features entram nos blocos dos níveis 1–4, sempre com o mesmo total.

Origin + 15 blocks in 5 levels. The input is a deposit: features enter the level 1–4 blocks, always with the same total.

02 · CAMADA / LAYER

Redistribuição aprendível

Learnable redistribution

Cada rodada multiplica o estado por uma matriz 16×16 cujas colunas somam 1 (softmax por coluna): mistura valor sem nunca criar ou destruir — o invariante do Block155Learn.

Each round multiplies the state by a 16×16 matrix whose columns sum to 1 (column-softmax): it mixes value without ever creating or destroying it — the Block155Learn invariant.

03 · NÃO-LINEARIDADE

Bônus por limiar

Threshold bonus

Blocos acima da média da pirâmide ganham bônus proporcional — a regra original de bônus/perda do 15/5. Matematicamente, é o mesmo "joelho" do ReLU das redes profundas.

Blocks above the pyramid mean earn a proportional bonus — the original 15/5 bonus/loss rule. Mathematically it is the same "kink" as the ReLU of deep networks.

04 · RESPOSTA / ANSWER

Lida na base

Read at the base

Depois de 3 rodadas, o valor desce a pirâmide. A classe prevista é o bloco da base (nível 5) onde mais valor aterrissou — a resposta é onde o valor chega.

After 3 rounds, value flows down the pyramid. The predicted class is the base block (level 5) where most value landed — the answer is where the value arrives.

# A matemática, sem esconder nada

# The mathematics, nothing hidden

Uma inferência são 3 rodadas de duas equações. Só isso.

One inference is 3 rounds of two equations. That is all.

u = T·x — redistribuição / redistribution · T = softmax-coluna(θ) ⇒ Σcoluna = 1: conservação exata / exact conservation
x′ = u + g·relu(u − média(u)) — bônus por limiar / threshold bonus: o joelho não-linear / the nonlinear kink
classe = argmax( escala·xbase + viés ) — leitura nos 5 blocos da base / readout at the 5 base blocks

O treino é retropropagação escrita à mão em numpy puro (sem frameworks), atravessando o softmax por coluna, o bônus e a leitura — e verificada contra diferenças finitas com erro máximo de 1,4 × 10⁻¹⁰ na suíte de testes. Redes lineares-por-partes são aproximadores universais: com blocos suficientes, essa arquitetura aprende qualquer função contínua.

Training is backpropagation written by hand in pure numpy (no frameworks), through the column-softmax, the bonus and the readout — verified against finite differences with max error 1.4 × 10⁻¹⁰ in the test suite. Piecewise-linear networks are universal approximators: with enough blocks, this architecture learns any continuous function.

# Uso rápido

# Quick start

# Python (numpy puro / pure numpy)
>>> from blockz10_neural import BlockNet, iris
>>> f_tr, y_tr, f_te, y_te = iris()
>>> net = BlockNet(n_classes=3, rounds=3)
>>> net.train(f_tr, y_tr, steps=5000, lr=1.2)
>>> net.accuracy(f_te, y_te)
0.933
